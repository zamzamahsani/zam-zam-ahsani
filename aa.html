AKTIVITAS

Eksperimen

let a = 20;
let b = 4;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
a + b =24
a - b =16
a * b =80
a / b =5
a % b =0
💡 Apa yang kamu temukan?

Operator %, atau modulus, menghasilkan sisa pembagian. Karena 20 dibagi 4 tidak bersisa, hasilnya adalah 0.

Challenge: Warung Digital

Buat program yang meminta nama makanan, harga, dan jumlah, kemudian tampilkan total dan diskon 10%.

let makanan = prompt("Nama makanan:");
let harga = prompt("Harga:");
let jumlah = prompt("Jumlah:");

let total = harga * jumlah;

console.log(makanan);
console.log(harga);
console.log(jumlah);
console.log(total);

let diskon = total * 10 / 100;
let bayar = total - diskon;

console.log(total);
console.log(diskon);
console.log(bayar);

Jumlah: 2

08
AKTIVITAS

Debugging

let harga = 5000;
let jumlah = 3;
let total harga = harga * jumlah;
console.log(total harga);

❌ Kesalahan

Nama variable tidak boleh menggunakan spasi. total harga dianggap bukan nama variable yang valid.

✅ Perbaikan kode

let harga = 5000;
let jumlah = 3;
let totalHarga = harga * jumlah;
console.log(totalHarga);

BAHAN AJAR

Ringkasan Materi

1. Mengingat Variable

Variable adalah tempat untuk menyimpan data.

let nama = "Budi";
let umur = 17;
let nilai = 85;

2. Input – Process – Output

INPUT
↓
PROCESS
↓
OUTPUT
let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);

3. Output dengan console.log()

console.log("Halo");
let nama = "Budi";
console.log(nama);
console.log("Nama saya adalah", nama);

4. Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
Pengguna mengetik → prompt() → variable → console.log()

5. Operator Aritmatika

OperatorFungsiContohHasil
+Penjumlahan10 + 515
-Pengurangan10 - 55
*Perkalian10 * 550
/Pembagian10 / 52
%Sisa pembagian10 % 31

6. Variable dalam Perhitungan

let nilai1 = 80;
let nilai2 = 90;
let total = nilai1 + nilai2;
console.log(total);

7. Contoh Kehidupan Nyata

Harga satu buku Rp10.000 dan membeli 3 buku.

let harga = 10000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);
Hasilnya: Rp30.000

8. Pola Dasar Program

let data1 = ...;
let data2 = ...;
let hasil = data1 OPERASI data2;
console.log(hasil);

let panjang = 10;
let lebar = 5;
let luas = panjang * lebar;
console.log(luas);

9. Catatan tentang prompt()

Hasil prompt() secara umum diterima sebagai teks/string. Untuk mengubahnya menjadi angka dapat digunakan Number().

let angka = Number(prompt("Masukkan angka:"));
